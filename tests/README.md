# テスト

Core Audio API は Windows の実際の音声セッションを必要とするため、手動で起動し、再生中アプリの音量・ミュートを確認する。

## 非アクティブ時の半透明表示

1. ミキサーをアクティブなまま10秒以上置き、不透明のままであることを確認する。
2. 背後に文字のあるウィンドウを置いてそちらを操作し、10秒後にミキサー全体が半透明になり、背後の文字が見えることを確認する。
3. ミキサーをクリック、または Alt+Tab でアクティブにし、すぐに不透明へ戻ることを確認する。
4. 非アクティブにして10秒以内に戻り、半透明化がキャンセルされることを確認する。再び非アクティブにした場合は、その時点から10秒後に半透明になることを確認する。
5. 半透明化の待機中に終了し、プロセスが終了することを確認する。
6. 起動直後、上部の「DOPA RUSH」メニューで「非アクティブ時に半透明化」にチェックが付いていることを確認する。チェックを外してから非アクティブにして10秒以上待ち、不透明のままであることを確認する。
7. メニューから再びONにし、非アクティブにして10秒後に半透明になることを確認する。半透明の状態や待機中にもOFFへ切り替え、不透明表示を保つことを確認する。
8. OFFにしてからアプリを終了・再起動し、「非アクティブ時に半透明化」がONに戻ることを確認する。
